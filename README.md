# Development of an AI Agent for Intelligent Predictive Maintenance in Industry 5.0 Using LightGBM and Large Language Models

## Project Description

This project develops an AI-based predictive maintenance decision-support system for Industry 5.0.

The system uses LightGBM to predict machine failure from machine sensor values. SHAP is used to explain predictions, a local maintenance knowledge base provides domain information, and Llama 3 through Ollama generates human-readable maintenance analysis.
